# Belajar GitHub Harian

Repo ini menampung hasil belajar harian dari GitHub: skill, tools, dan teknik baru yang diriset setiap hari untuk kebutuhan kerja marselhamenda.

## Cara kerja

- Setiap hari sekitar 07:41 WITA, ada riset otomatis di GitHub pada 4 bidang: agent skills, otomasi video (ffmpeg/TTS/subtitle), tooling bounty & airdrop, dan konten faceless (TikTok Shop affiliate, YouTube anak, monetisasi FB).
- Temuan dicatat di [LOG.md](LOG.md) dan dilaporkan ke pemilik repo beserta nilai kegunaannya.
- Kode dari repo temuan TIDAK pernah diunduh/dijalankan otomatis — adopsi selalu lewat persetujuan pemilik dulu.

## Format catatan

Setiap temuan dicatat dengan: tanggal, nama repo + link, bidang, ringkasan 1–2 baris, dan nilai kegunaan (Sangat berguna / Berguna / Kurang berguna) beserta alasannya.
